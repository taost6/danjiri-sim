# Danjiri Sim

だんじり曳行時の走行速度と旋回時の横転リスクの関係を体験する、JavaScript製の教育用シミュレーターです。外部ライブラリ・通信・サーバーは不要で、`index.html` をブラウザで開くだけで動作します。

## 操作

- `↑` / `W`：曳く（加速）
- `↓` / `S` / `Space`：減速
- `P`：一時停止／再開
- `R`：現在のコースをやり直す
- スマートフォン：画面内の「引く」「減速」を長押し

コースを1周すると「次のコースへ」が表示されます。全6コースで、丸みのある周回路から始まり、曲率の変化、S字カーブ、連続する急旋回へと徐々に複雑になります。コースごとに形が違い、右カーブだけでなく、左・右への切り返しもあります。横転した場合は同じコースから再挑戦できます。

## 簡易力学モデル

- 山車の質量（設定値）：4,000 kg
- 車輪間隔：1.6 m
- 重心高さ：1.7 m
- 曳行・制動性能：全6コースで共通
- 各コースの中心線をスプライン曲線で構成し、局所曲率を計算
- 局所横加速度の大きさ `v² / r` と静的な横転限界 `g b / (2 h)` の比を表示
- 曲率の向きに応じた簡易ロール運動（左右の切り返しを反映）
- 前方の曲線までの距離および安全側の目安速度を表示

**実物のだんじりの動力学を精密に再現したものではありません。** 曳き手の張力、人数・体重移動、木製車輪の滑り、段差、路面の傾斜や変形、ブレーキの遅れなどは省略しています。距離と速度はゲーム内で仮定したスケールに基づきます。

観客はコース周辺に分散して描画します。横転時の路肩への逸脱と周囲の人の動きは控えめな模式的表現であり、実際の事故や人的被害を再現・予測するものではありません。**祭礼の現場での運行判断・安全基準として利用しないでください。**

## GitHub Pagesへの公開

公開リポジトリのルートに `index.html`、`LICENSE`、`README.md` を配置し、**Settings → Pages → Deploy from a branch → main / (root)** に設定してください。すでに公開している場合は該当ファイルを更新します。ZIPファイルはGitHubのブラウザアップロード画面では自動展開されません。
